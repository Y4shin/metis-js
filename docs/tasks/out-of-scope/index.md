# out-of-scope

Rejected requests live here. A note records what was asked for, who asked,
when, and why it was refused, so that the same request is answered once
instead of re-litigated.

Wayfinder and the skills that defer work add notes here through
`tw_record_out_of_scope`. An entry is not a backlog item: nothing here is
scheduled, and a refusal is revisited only when a new request names the note
and argues that the reason no longer holds.
