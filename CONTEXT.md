# metis-js

The ubiquitous language of this repository. Every skill, commit message, and
artifact uses these terms with exactly these meanings. A term belongs here
once the project has settled it; until then the term is not yet safe to reuse.

## Language

No terms recorded yet.

When a term is settled, record it in this shape:

**Term**:
One or two sentences defining what it names in this project, followed by where
it lives in the code when that is not obvious.
_Avoid_: the words that are close but wrong.

Rules for this file:

- One meaning per term and one term per meaning. A second meaning gets its own
  term.
- Record a term when it is decided, not when it is proposed.
- The `_Avoid_` line names the near-miss words, so a later reader does not
  reintroduce them.
- A change to a term's meaning is a change to this file first.
